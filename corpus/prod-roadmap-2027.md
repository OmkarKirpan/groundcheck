# Halvicor Relay Roadmap 2027

Internal and confidential. Not for customers.

## Relay 5.0

Halvicor Relay 5.0 is planned for the second quarter of 2027. Its headline feature is offline mode for devices without network coverage.

## API changes

API v1 will be deprecated on 31 March 2027. Customers will get at least 90 days of notice.
